# Sheet Metal Trough Assembly

## Overview

This project is a sheet metal trough assembly created in Autodesk Inventor. It includes 3D part modeling, assembly modeling, flat patterns, BOM preparation, and 2D manufacturing drawings.

All major dimensions were set up as parameter-driven values, allowing the main part sizes, flange lengths, bend locations, and assembly-related dimensions to be updated more efficiently through the parameter table.

## Tools Used

- Autodesk Inventor
- Sheet metal modeling
- Parametric CAD design
- 2D manufacturing drawings
- BOM documentation

## Project Scope

- Modeled sheet metal parts and assembly
- Created flat patterns for fabrication reference
- Prepared part and assembly drawings
- Added BOM, item balloons, bend notes, and key dimensions
- Checked fit between mating parts and rivet hole locations

## Design Focus

- Parameter-driven dimensions
- Sheet metal bend direction and relief
- Riveted assembly structure
- Drawing clarity for fabrication
- Manufacturability and assembly fit
