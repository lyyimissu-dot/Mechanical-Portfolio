# Circular Economy Assessment for AS/RS Equipment

MEng research project developed into a manuscript currently under review. I contributed as the third author.

This project applies circular economy assessment to automated storage and retrieval systems (AS/RS), using stacker crane configuration scenarios as the industrial equipment case study.

## Focus Areas

- AS/RS lifecycle analysis
- 9R circular economy strategy mapping
- Circularity metrics and KPI selection
- Straight-track vs. curved-track stacker crane comparison
- CE impact evaluation for equipment configuration decisions
